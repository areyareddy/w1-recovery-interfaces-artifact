### Detailed Analysis and Proof

**Problem Analysis:**
We need to determine the cardinality of a set `S` of real numbers defined by a specific condition:
- A real number `x` is in `S` if and only if:
  1. `0 ≤ x ≤ π`,
  2. `sin(π/2 * cos x) = cos(π/2 * sin x)`.

Our goal is to prove that `S` has exactly two elements.

**Approach:**
1. Understand the condition `sin(π/2 * cos x) = cos(π/2 * sin x)`:
   - The range of `cos x` is `[-1, 1]`, so `π/2 * cos x` is in `[-π/2, π/2]`. Therefore, `sin(π/2 * cos x)` is well-defined and its range is `[-1, 1]`.
   - Similarly, `sin x` is in `[-1, 1]` when `x ∈ [0, π]`, so `π/2 * sin x` is in `[-π/2, π/2]` and `cos(π/2 * sin x)` is well-defined and its range is `[-1, 1]`.
   - The condition is non-trivial because it relates the sine and cosine of different arguments involving `cos x` and `sin x`.

2. Simplify the condition:
   - Let `y = cos x` and `z = sin x`. Then `y² + z² = 1` and the condition becomes `sin(π/2 * y) = cos(π/2 * z)`.
   - The range of `y` is `[-1, 1]` and `z` is in `[-1, 1]` because `x ∈ [0, π]` (so `z ≥ 0` in this case).
   - The condition can be rewritten using the identity `cos(π/2 * z) = sin(π/2 - π/2 * z)` as `sin(π/2 * y) = sin(π/2 - π/2 * z)`.
   - Since `sin` is injective on `[-π/2, π/2]`, we can deduce that `π/2 * y = π/2 - π/2 * z + 2πk` or `π/2 * y = π - (π/2 - π/2 * z) + 2πk` for some integer `k`. However, given the ranges of `y` and `z`, the only possible solutions are `π/2 * y = π/2 - π/2 * z` and `π/2 * y = π - (π/2 - π/2 * z)`, but the latter simplifies to `π/2 * y = π/2 + π/2 * z`, which is unlikely to hold for `y, z ∈ [-1, 1]` (but we must verify this).

   But a simpler approach is to consider specific values of `x` that satisfy the condition and then check if there are others.

3. Find specific solutions:
   - Try `x = 0`: `cos 0 = 1`, `sin 0 = 0`. The condition is `sin(π/2 * 1) = cos(π/2 * 0)` ⇒ `sin(π/2) = cos(0)` ⇒ `1 = 1`, which holds. So `0 ∈ S`.
   - Try `x = π`: `cos π = -1`, `sin π = 0`. The condition is `sin(π/2 * (-1)) = cos(π/2 * 0)` ⇒ `sin(-π/2) = cos(0)` ⇒ `-1 = 1`, which does not hold. So `π ∉ S`.
   - Try `x = π/2`: `cos(π/2) = 0`, `sin(π/2) = 1`. The condition is `sin(π/2 * 0) = cos(π/2 * 1)` ⇒ `sin(0) = cos(π/2)` ⇒ `0 = 0`, which holds. So `π/2 ∈ S`.
   - Try `x = π/6`: `cos(π/6) = √3/2`, `sin(π/6) = 1/2`. The condition is `sin(π/2 * √3/2) = cos(π/2 * 1/2)` ⇒ `sin(√3 π/4) = cos(π/4)`. But `sin(√3 π/4) = √(1 - cos²(√3 π/4))` is not obviously equal to `cos(π/4) = √2/2`. Numerically, `√3 π/4 ≈ 1.36`, `sin(1.36) ≈ 0.98`, `√2/2 ≈ 0.707`, so they are not equal. Hence, `π/6 ∉ S`.

   It seems that only `x = 0` and `x = π/2` are solutions in `[0, π]`. To confirm this, we need to check if there are other solutions.

4. Prove that no other solutions exist:
   - The condition is `sin(π/2 * cos x) = cos(π/2 * sin x)`.
   - Notice that `cos(π/2 * sin x) = sin(π/2 - π/2 * sin x)` because `cos θ = sin(π/2 - θ)`.
   - So the condition becomes `sin(π/2 * cos x) = sin(π/2 - π/2 * sin x)`.
   - Since `sin` is injective on `[-π/2, π/2]`, we need to consider when `π/2 * cos x` and `π/2 - π/2 * sin x` are in `[-π/2, π/2]` and their sines are equal.
   - For `x ∈ [0, π]`, `sin x ≥ 0` and `cos x ∈ [-1, 1]`.
     - `π/2 * cos x ∈ [-π/2, π/2]` is always true.
     - `π/2 - π/2 * sin x ∈ [π/2 - π/2, π/2 - 0] = [0, π/2]` because `sin x ∈ [0, 1]` when `x ∈ [0, π]`.
   - Therefore, `sin(π/2 * cos x) = sin(π/2 - π/2 * sin x)` implies that either:
     1. `π/2 * cos x = π/2 - π/2 * sin x + 2πk` for some integer `k`, or
     2. `π/2 * cos x = π - (π/2 - π/2 * sin x) + 2πk` for some integer `k`.
     But since `π/2 * cos x ∈ [-π/2, π/2]` and `π/2 - π/2 * sin x ∈ [0, π/2]`, the only possible `k` is `k = 0` in the first case and `k = 0` in the second case (but the second case gives `π/2 * cos x = π/2 + π/2 * sin x`, which is impossible because the left side is at most `π/2` and the right side is at least `π/2` and would require `cos x = 1 + sin x`, but `sin x + cos x ≤ √2 < 2`, so `cos x = 1 + sin x` is impossible unless `sin x = 0` and `cos x = 1`, i.e., `x = 0`).

     - Case 1: `π/2 * cos x = π/2 - π/2 * sin x` ⇒ `cos x + sin x = 1`.
       - Squaring both sides: `cos² x + sin² x + 2 sin x cos x = 1` ⇒ `1 + sin 2x = 1` ⇒ `sin 2x = 0`.
       - So `2x = πk` for some integer `k` ⇒ `x = πk/2`.
       - For `x ∈ [0, π]`, the solutions are `x = 0` (`k = 0`), `x = π/2` (`k = 1`), and `x = π` (`k = 2`).
       - But `x = π` does not satisfy `cos x + sin x = 1` (`-1 + 0 ≠ 1`), so only `x = 0` and `x = π/2` are solutions.
     - Case 2: `π/2 * cos x = π - (π/2 - π/2 * sin x)` ⇒ `π/2 * cos x = π/2 + π/2 * sin x` ⇒ `cos x = 1 + sin x`.
       - This implies `cos x - sin x = 1`. Squaring both sides: `cos² x + sin² x - 2 sin x cos x = 1` ⇒ `1 - sin 2x = 1` ⇒ `sin 2x = 0` ⇒ `2x = πk` ⇒ `x = πk/2`.
       - The solutions in `[0, π]` are `x = 0`, `x = π/2`, `x = π`.
         - For `x = 0`: `cos 0 - sin 0 = 1` holds.
         - For `x = π/2`: `cos(π/2) - sin(π/2) = 0 - 1 = -1 ≠ 1` does not hold.
         - For `x = π`: `cos π - sin π = -1 - 0 = -1 ≠ 1` does not hold.
       - So the only solution is `x = 0`, but it was already found in Case 1.
   - Therefore, the only solutions in `[0, π]` are `x = 0` and `x = π/2`.

5. Conclusion:
   - The set `S` is `{0, π/2}` and has cardinality `2`.

**Proof Sketch:**
1. Show that if `x ∈ S`, then `x = 0` or `x = π/2`.
   - Use the condition `sin(π/2 * cos x) = cos(π/2 * sin x)` to derive `cos x + sin x = 1`.
   - Solve `cos x + sin x = 1` in `[0, π]` to get `x = 0` or `x = π/2`.
2. Show that both `0` and `π/2` are in `S`.
   - Directly verify the condition for each.
3. Conclude that `S = {0, π/2}` and `card S = 2`.

### Step-by-Step Abstract Plan

1. **Step 1: Prove that if `x ∈ S`, then `x = 0` or `x = π/2`.**
   - Assume `x ∈ S`, so `0 ≤ x ≤ π` and `sin(π/2 * cos x) = cos(π/2 * sin x)`.
   - Rewrite the condition using `cos θ = sin(π/2 - θ)` to get `sin(π/2 * cos x) = sin(π/2 - π/2 * sin x)`.
   - Deduce that `π/2 * cos x = π/2 - π/2 * sin x` because the sine function is injective on `[-π/2, π/2]` and the arguments are in this range.
   - Simplify to `cos x + sin x = 1` and solve in `[0, π]` to get `x = 0` or `x = π/2`.

2. **Step 2: Prove that `0 ∈ S` and `π/2 ∈ S`.**
   - Verify that `sin(π/2 * cos 0) = cos(π/2 * sin 0)` and `sin(π/2 * cos (π/2)) = cos(π/2 * sin (π/2))` hold.

3. **Step 3: Conclude that `S = {0, π/2}` and `card S = 2`.**
   - Use the previous steps to show that `S` has exactly two elements.
